# Security Policy

## Supported versions

This project is pre-1.0. Security fixes are targeted at the latest `main` branch state.

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities.

Report privately with:
- Description of the issue
- Reproduction steps or proof of concept
- Impact assessment
- Suggested fix (optional)

Use one of these channels:
- Private security advisory on GitHub (preferred)
- Direct maintainer contact

## Response process

- We will acknowledge receipt as soon as possible.
- We will assess severity and propose a remediation timeline.
- We will coordinate disclosure and release notes after a fix is available.
