# ducklake-agent v0.1.0

## Highlights

- WASM-first analytics stack with:
  - DuckDB-WASM runner and browser query UI
  - Rust control-plane and range gateway
  - MinIO object storage integration
- Budget and capability enforcement for agent-facing SQL execution.
- Lineage and artifact tracking for query outputs.

## Security / operations

- Runner remote URL allow-list and input-byte guardrails.
- Optional API auth:
  - `x-api-key` (`API_KEYS`)
  - JWT bearer (`JWT_HS256_SECRET`)
- Optional API->Runner shared-token auth (`RUNNER_AUTH_TOKENS`).
- Production override + env template:
  - `docker-compose.production.yml`
  - `.env.production.example`

## Upgrade / deploy notes

1. Copy `.env.production.example` to `.env.production`.
2. Set real secrets/origins.
3. Launch with:
   - `docker compose --env-file .env.production -f docker-compose.yml -f docker-compose.production.yml up -d --build`
